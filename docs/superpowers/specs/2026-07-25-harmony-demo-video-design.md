# HarmonyOS 作品演示视频设计

## 目标

制作一条不超过 5 分钟的横屏 MP4，完整展示
MindSpore 掌中宝 HarmonyOS 版的核心能力和原生 UI。

成片规格：

- 1920×1080，16:9；
- H.264 MP4；
- 30fps；
- 目标时长约 4 分 20 秒；
- 无配音；
- 使用简洁中文字幕和轻科技感纯音乐。

## 选定方案

采用“评审型演示”结构，而不是逐项长录或宣传快剪。

每个功能只保留一次输入、处理状态和结果，重复的相册选择过程直接剪短。
这样既能证明功能真实可用，也能在 5 分钟内保持清晰节奏。

实时摄像头功能只在体验中心总览中出现，不录制实际推理。
当前 DevEco 只枚举没有人物画面的物理 UVC；对应能力改用相册输入的功能展示，
不伪造摄像头成功结果。

## 分镜

| 时间 | 内容 |
|---|---|
| 0:00–0:12 | 作品名、HarmonyOS 原生应用定位 |
| 0:12–0:35 | 体验中心、新 UI、功能分区、悬浮底部导航 |
| 0:35–1:10 | 图片对象检测、图像分类 |
| 1:10–1:45 | 骨架检测、手势识别 |
| 1:45–2:15 | 相册人像分割与结果 |
| 2:15–2:50 | OCR 文本提取 |
| 2:50–3:20 | 中英文本翻译 |
| 3:20–3:50 | 风格迁移和诗词创作 |
| 3:50–4:08 | 学院页、“我的”页和原生页面设计 |
| 4:08–4:20 | 核心亮点总结、结束画面 |

允许根据真实操作时长在相邻段落间移动数秒，但最终不得超过 4 分 50 秒。

## 演示素材

优先使用仓库已有、来源可追溯的相册 fixture：

- 图像分类：`grace_hopper.jpg`、`yellow_labrador.jpg`
- 对象检测：`yellow_labrador.jpg` 或 `person.jpg`
- 骨架检测：`person.jpg`
- 手势识别：`four.jpg`
- 人像分割：`person.jpg`
- OCR：`chinese_sentence.png`
- 风格迁移：从上述人物或分类图片中选择一张

文本翻译使用简短、易核对的中英文句子。诗词创作使用一个短主题，
避免长时间等待或大段结果滚动。

只展示实际成功的功能结果。某个 fixture 与当前模型不匹配时，
换用仓库内另一张 fixture，不修改模型输出或页面状态。
如果当前图像分类 route 只接受 camera，则用相册静态场景检测替代该段，
图像分类只在功能总览中出现。

## 录制

HDC 负责全部模拟器操作：

- 安装和启动 HAP；
- 上传图片到图库；
- 原生触点点击、滑动和文本输入；
- `dumpLayout` 用于定位控件；
- 截图用于录制前后核对。

设备镜像没有 `screenrecord`，因此使用 OBS 只捕获 DevEco 模拟器窗口。
每个功能单独录成一个原始片段，不录一条不可编辑的长视频。

录制过程：

1. 安装最终可运行 HAP并清理无关弹窗。
2. 把选定 fixture 上传到模拟器图库。
3. 为每个功能准备确定的 HDC 操作序列。
4. OBS 开始录制单个功能。
5. HDC 执行输入、等待和结果展示。
6. OBS停止录制。
7. 保存原始 MP4、对应功能名和操作记录。

不录制桌面上的无关窗口、路径、终端或隐私内容。

## ChatCut 时间线

创建一个新的 ChatCut 项目，保留可编辑多轨结构：

- 主视频轨：按分镜排列每个原始 OBS 片段；
- 字幕/标题轨：功能名称、输入说明、结果亮点；
- 音乐轨：一条无歌词轻电子音乐；
- 必要时使用一条背景或装饰轨承接竖屏模拟器两侧留白。

模拟器画面保持纵向比例，居中放置在 16:9 画布。
两侧只放简短标题和结果说明，不堆叠参数。

转场只使用短淡入淡出；不加入炫技转场、音效包或无关 B-roll。
相册选择和模型等待只保留足以证明真实操作的时间。

## 视觉规范

- 主色延续应用的 Harmony 蓝和白色；
- 字体清晰、无描边堆叠；
- 功能标题最多两行；
- 结果字幕使用短句；
- 字幕不遮挡应用的状态栏、结果图和主操作按钮；
- 开场和结束页使用同一视觉体系；
- 音乐无歌词，约 105–115 BPM，音量稳定。

## 字幕内容原则

字幕只说明当前可见行为：

- 输入是什么；
- 使用了什么能力；
- 页面产生了什么结果；
- 哪些处理在端侧完成。

不使用“全部功能完美运行”“完全领先”等无法从画面证明的宣传语。

## 验证与交付

录制后先检查每个原始片段：

- 操作和结果完整；
- 没有系统错误或无关弹窗；
- 没有桌面隐私内容；
- 文字可读；
- 帧率和分辨率一致。

ChatCut 完成结构剪辑后：

1. 读取时间线结构，确认片段顺序、时长和轨道无重叠。
2. 渲染关键帧，检查开场、每类功能和结尾。
3. 确认总时长小于 5 分钟。
4. 使用 ChatCut 导出 1080p、H.264、30fps MP4。
5. 下载到本机 Downloads 目录，避免覆盖已有文件。
6. 报告文件绝对路径、大小、分辨率和时长。

## 非目标

- 不录制当前没有人物输入的实时摄像头推理。
- 不加入中文配音。
- 不为视频修改模型结果或伪造成功状态。
- 不使用本地 FFmpeg 预剪成一条扁平视频替代 ChatCut 时间线。
- 不增加与作品无关的动画、B-roll 或复杂片头。
