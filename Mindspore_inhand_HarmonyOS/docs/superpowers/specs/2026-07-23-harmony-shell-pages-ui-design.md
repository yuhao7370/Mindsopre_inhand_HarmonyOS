# HarmonyOS 普通功能页 UI 设计

## 范围

本阶段重做以下三个页面：

- `WebPage`；
- `QrCodePage`；
- `PoetryPosterPage`。

启动页、舞蹈页、AI 运行页和已经验收的 Experience、College、Me 不在本阶段修改。现有路由、Web JavaScript bridge、二维码保存授权、海报截图/保存/分享和隐藏入口状态保持不变。

## 设计取向

沿用已批准的 A+C HarmonyOS 原生轻量方向：

- 白色或浅灰背景、左对齐标题、品牌蓝仅用于操作和状态；
- 使用系统 `SymbolGlyph`，不再使用两套 Android 返回位图；
- 卡片只保留 `1vp #E8EDF5` 淡边框，不使用常驻阴影；
- 高度由内容驱动，支持系统字体最大 `3.2×`；
- 不新增页面 Shell、导航框架、设计系统或图片资源。

三个页面确有同构标题栏，因此只新增一个轻量标题栏组件。它只负责标题、返回操作和可选尾部操作，不持有页面背景、滚动、Web、sheet 或业务状态。

## 共享标题栏

- 返回图标使用 `$r('sys.symbol.chevron_backward')`。
- 二维码尾部操作使用系统扁平更多图标。
- 返回和尾部操作的触控区域为 `48×48vp`。
- 标题栏使用 `minHeight`，不使用固定 `56vp` 高度。
- 标题左对齐，允许两行；大字体时标题栏自然增高。
- 返回和更多操作提供明确的可访问性名称。
- 标题栏左右边距为 `16vp`。

## WebPage

### 保留

- `titleKey/url/routeName` 参数及 URL 映射；
- 本地 `privacy.html`；
- 普通远端页面和智能写诗页面；
- bridge 名称 `android`、方法 `getGeneratePoetry`；
- 原诗文本原样传入 `PoetryPosterPage`，不 trim；
- 返回操作继续退出当前 router 页面。

### UI

- 使用共享标题栏。
- WebView 直接作为页面主体，不套卡片或头图。
- 始终保留 `2vp` 进度槽，加载时显示进度，完成后透明，避免内容跳动。
- 只在主文档加载失败时显示简短失败状态和“重试”按钮；子资源失败不覆盖整页。
- 重试复用现有 `WebviewController` 和目标 URL，不创建第二套 Web 状态机。

## QrCodePage

### 保留

- 页面入口继续隐藏；
- 二维码资源继续使用 `app.media.my_qr_code`；
- 保存继续由 HarmonyOS `SaveButton` 授予短期图库写入权限；
- 保存成功关闭 sheet，失败保持 sheet；backdrop、取消和系统返回关闭 sheet；
- `saveInFlight` 继续阻止重复写入。

### UI

- 使用共享标题栏和系统更多图标。
- 二维码置于白色区域，最大宽度 `300vp`，保留 quiet zone。
- 外层只使用 `1vp #E8EDF5` 淡边框；二维码本体不裁圆、不透明、不加阴影。
- 使用 HarmonyOS `bindSheet` 承载现有 `SaveButton`，由系统处理安全区、拖拽和返回。
- 主操作最小高度 `48vp`。
- 保存期间禁用重复操作并显示进行中文案。
- 保存失败文案显示在 sheet 内并允许重试；成功文案回到主页面显示。

## PoetryPosterPage

### 保留

- `poem` 参数原样显示；
- `poetryPosterComponentId` 只包住成品海报；
- 截图继续等待渲染完成；
- PixelMap 继续由调用方在成功和失败路径释放；
- 保存继续输出 JPEG 和图库 URI；
- 分享继续使用保存后的 URI、ShareKit 和本地化标题/描述；
- 成品继续包含诗文、MindSpore 标识、署名和二维码。

### UI

- 使用共享标题栏。
- 水墨海报是页面唯一视觉主体，不再增加外层重卡片。
- 背景保持比例，不使用 `ImageSize.FILL` 任意拉伸。
- 诗文取消固定 `28vp` 行高，使用自然行高；左右 padding 为 `16–24vp`。
- 海报允许内容驱动增高，不能裁掉长诗或放大后的文字。
- 署名使用可读的次级文字色，不使用低对比度 muted 色。
- 保存和分享使用单列全宽按钮，最小高度 `48vp`。
- 一个 `actionInFlight` 状态同时阻止重复保存和重复分享；不新增任务框架。
- 进行中、成功、失败和可重试状态紧邻操作区显示，且不进入海报截图。

## 可访问性与颜色

- 所有操作目标至少 `44vp`，本阶段标题栏和主按钮使用 `48vp`。
- 长中文和英文标题允许两行。
- 状态使用文字表达，不只改变颜色。
- 小号可读蓝色文字必须达到普通文字对比度；装饰蓝不承担唯一语义。
- 默认和 `3.2×`、竖屏和横屏下，操作区均可滚动到达。

## 守卫与测试

- 删除两个旧守卫对 Android 返回图片哈希、`11×22vp` 图片和 `40×40vp` 热区的要求。
- 新守卫只检查共享标题栏使用系统 symbol、返回回调、`48vp` 触控、二维码尾部操作和页面业务契约。
- 保留现有二维码保存、sheet reducer、海报保存/释放/分享、Web 映射和 bridge 测试。
- 海报测试不再固定旧 Android 视觉数值，改为验证 snapshot 边界、资源语义、自然行高和操作区位于 snapshot 外。
- Web 只新增一个纯加载状态测试，不创建通用异步状态机。

## 模拟器验收

### Web

- 本地隐私页、普通远端页、长英文标题和智能写诗页可打开并返回。
- 断网时失败状态可见，重试后恢复；进度槽不引发布局跳动。
- bridge 仍能进入海报页，诗文空格和换行不变。

### 二维码

- 二维码仍可被真实扫码工具识别。
- sheet 的取消、backdrop、系统返回、成功和失败状态符合现有 reducer。
- 失败文案在 sheet 内可见；快速连点只写入一次。
- 默认和 `3.2×` 下保存、取消和错误文案均可达。

### 海报

- 短诗、长诗、多行、首尾空格和中英文均不重叠。
- 保存成品不包含标题栏、按钮或状态文案。
- 快速连点只启动一次保存或分享；失败后可重试且诗文不丢失。
- 默认和 `3.2×` 下页面可滚到全部操作。
