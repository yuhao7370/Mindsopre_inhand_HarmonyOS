# HarmonyOS 学院与我的页面 UI 设计

## 范围

本阶段只重做主页面的“学院”和“我的”两个标签页。体验中心、底部导航、Web 页面和 AI 运行时逻辑不在本阶段修改。

现有路由、学习进度、对话框、Web 跳转、版本读取、分享状态以及 `visibleByDefault` 可见性保持不变。

## 设计取向

沿用已批准的 A+C 方向：

- 使用 HarmonyOS 原生布局、滚动、按钮和按压反馈。
- 页面保持白色与浅灰背景、左对齐层级、品牌蓝强调。
- 卡片仅保留 1vp 浅蓝灰边框，不使用常驻阴影。
- 所有文本容器使用最小高度和内容驱动布局，支持系统字体缩放。
- 不新增通用设计系统或页面 Shell。当前窗口已由系统避让安全区，继续使用现有 `MainPage` 普通纵向布局。

## 学院页

### 页面结构

学院页使用一个原生 `Scroll`：

1. 紧凑标题区；
2. 学习入口列表；
3. 快速开始入口；
4. 页尾说明。

页面背景为 `#F7F8FA`，左右边距 16vp，主要间距遵循 8vp 网格。

### 标题区

- 不再使用 210vp 渐变头图。
- 使用内容驱动的浅色标题区，最小高度 112vp。
- 标题左对齐，28fp、Bold；副标题 14fp、次级文字色。
- 右侧可显示一枚扁平学习图标，但图标不参与容器高度计算。
- 标题区不吸顶、不改变圆角，随页面自然滚出。

### 学习入口

- 删除旧固定高度时间线和装饰进度点。
- Summary、Cloud、FAQ、Forum 使用单列白色入口卡片。
- 卡片最小高度 72vp，圆角 16vp，边框 `#E8EDF5`，无阴影。
- 左侧为 36–40vp 扁平线性图标；中间标题允许两行；右侧为“查看”和箭头。
- 已访问状态使用蓝色勾选标记和可访问文本表达，不只依赖颜色。
- 整卡可点击；只有 Summary 或带 URL 的条目注册点击事件。

### 快速开始

- Quick Start 使用一张白色分组卡。
- Train、Inference、Applications、Video 采用两列网格。
- 每项最小高度 64vp，图标 28–32vp，标题允许两行。
- 已访问状态仅改变图标/文字强调和勾选标记，不增加粗边框或阴影。
- 点击后继续保存原有进度并打开原 URL。

### Summary 对话框

- 保留 `CustomDialog` 和原有文案/Logo。
- 宽度 86%，内容最大高度不超过可用区域的 72%。
- 长正文在内部 `Scroll` 中滚动。
- 确认按钮最小高度 44vp。
- 使用白色表面、20vp 圆角和轻量遮罩；不使用 Android 式底部分隔按钮复刻。

## 我的页

### 页面结构

- 删除渐变标题和 1vp 灰色横条。
- 页面使用白色背景、一个原生 `Scroll`。
- 顶部标题“我的”左对齐，最小高度 72vp，28fp、Bold。
- 内容左右边距 16vp。

### 内容

- 当前只有 Version 项可见，因此不制造空的设置分组或额外菜单。
- Version 以一张“关于应用”信息卡呈现：应用 Logo、应用名、版本号。
- 信息卡为白色、16vp 圆角、1vp `#E8EDF5` 边框、无阴影。
- Version 是静态信息，不注册点击事件，也不显示箭头。
- 未来某个条目重新可见时，沿用内容驱动的单列入口行；只有真实可导航或可操作项才能点击。
- 分享成功/失败状态只有在 Share 条目可见并触发后才显示，现阶段不新增占位状态。

## 图标资源

为本阶段生成并使用 10 枚独立扁平图标：

- 学院：summary、cloud course、quick start、FAQ、forum、train、inference、applications、video；
- 我的：version/about。

图标继续使用体验中心的 A 风格：256×256 透明 PNG、纯 2D、圆角细线、蓝色为主、少量青色强调；禁止渐变、阴影、玻璃、透视和 emoji。

旧 `college_*_checked/uncheck` 与 `me_version` 资源在新页面验证完成前保留，最终代码不得再引用旧占位图。

## 可访问性

- 所有可点击目标至少 44vp。
- 标题和卡片允许内容撑高，不设置固定最大高度。
- 长中文/英文标题允许两行；静态版本信息允许换行。
- 默认字号与 3.2× 应无裁切、重叠或底部导航碰撞。
- 状态不能只靠颜色表达。

## 验收

### 学院页

- 默认和 3.2× 字号下检查顶部、快速开始、列表底部。
- Summary 对话框在长正文和 3.2× 下可滚动，确认按钮可见。
- Summary、Cloud、四个 Quick Start、FAQ、Forum 均能打开并安全返回。
- 进度状态在重进页面后保持。

### 我的页

- 默认和 3.2× 字号下应用信息卡完整显示。
- 版本号与 `AppVersionService` 输出一致。
- 隐藏条目继续不显示，静态 Version 卡无虚假点击反馈。

### 工程

- LocalUnit 先以旧固定高度/旧 Android 视觉契约为 RED，再以新最小高度和可见性契约为 GREEN。
- main 与 ohosTest HAP 均验证 `arm64-v8a`、`x86_64`。
- 每个页面单独提交；每个页面完成后由独立子 agent 进行规范与 UI 缺陷复核。
