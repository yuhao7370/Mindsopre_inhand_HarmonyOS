# 自定义模型分区与学院 MNIST 教程设计

## 目标

1. “自定义模型”不再归入“高级区 / 视觉图像技术”，而是显示在独立的“自定义能力 / 模型工具”分区。
2. 学院页的本地快速入门改用 `docs/tutorials/college-hap/college-hap.zip` 中的新 MNIST 教程。
3. 用户可以从学院页导出完整教程包，在电脑上获得 Markdown、训练脚本、MNIST 数据、CKPT 和 MindIR。

## 体验中心分区

- `FeatureCatalog.ets` 新增独立分类 `custom-models`。
- `advanced-vision` 只保留场景检测、图片对象检测、实时对象检测和风格迁移。
- 新分区使用：
  - 分组标题：`自定义能力`
  - 分类标题：`模型工具`
  - 功能卡片：`自定义模型`
- 功能路由、图标和可见性保持不变。
- 分区位于高级视觉图像技术之后，不创建空分区。

## 学院教程内容

- 新教程仍为五章，顺序固定为：
  1. 准备环境和数据集
  2. 读懂 MNIST，喂给模型
  3. 搭一个 LeNet-5 网络
  4. 训练五轮，看准确率爬坡
  5. 导出模型，走向 HarmonyOS
- 页面继续使用原生折叠卡片，并且同一时间最多展开一章。
- ArkTS 内置内容以新 Markdown 为依据，不在运行时引入 Markdown 解析器或 WebView。
- 页面不显示外部下载链接；环境章节改为提示 MNIST 已包含在可导出的教程包中，保持纯本地学习路径。
- 新 Markdown 恢复到 `docs/tutorials/college-hap/`，方便直接审阅；完整数据、脚本和模型继续由 ZIP 统一承载，不在仓库中重复解压大体积 IDX 文件。
- 原有坏掉的“快速入门”和 FAQ 网络入口继续隐藏。

## 教程包导出

- 原始教程包：
  - 文件：`docs/tutorials/college-hap/college-hap.zip`
  - 大小：11,095,055 字节
  - SHA-256：`9D556E96FE27357B90FDC3814C5AB707FCEF8EED314981A6552B2A11B8C7DE42`
- 构建时使用同字节副本 `entry/src/main/resources/rawfile/college/college-hap.zip`。
- 学院页“本地快速入门”标题区域增加“导出教程包”按钮。
- 点击后调用 HarmonyOS 原生 `DocumentViewPicker.save`，默认文件名为 `MindSpore-MNIST-入门教程.zip`。
- 用户选定保存位置后，将 rawfile 字节完整写入目标 URI。
- 导出期间按钮不可重复触发；页面显示“正在导出”“导出完成”或“导出失败，请重试”。
- 用户取消系统保存器视为取消，不显示错误，也不破坏学院页当前展开状态。

## 错误处理

- rawfile 缺失、读取失败、目标文件无法写入或写入长度不完整均视为失败。
- 文件句柄必须在成功和失败路径中关闭。
- 已读取的教程内容和当前展开章节不受导出失败影响。
- 日志只记录通用失败原因，不输出目标 URI。

## 验证

- LocalUnit 先验证旧实现不满足以下契约，再实现：
  - 自定义模型只出现在独立分区，并位于高级视觉分区之后。
  - 五章标题、MNIST 规模、训练配置与实测结果和新文档一致。
  - 页面内容无 HTTP 链接和“参考视频”。
  - 导出状态能区分空闲、进行中、完成、失败与取消。
- PowerShell 校验 ZIP 的大小、SHA-256 和必需条目。
- 完整 LocalUnit、i18n 校验、主 HAP 构建和双 ABI HAP 校验通过。
- 在 DevEco Studio 模拟器使用 HDC 原生触点验证：
  - 新自定义能力分区位置；
  - 学院五章折叠；
  - 导出按钮能够打开系统保存器；
  - 学院顶部、教程区域和体验中心滚动后状态截图。

## 不包含

- 不在应用内训练 MNIST。
- 不在应用内解压或浏览整个教程包文件树。
- 不引入 Markdown 渲染库、WebView 页面或第三方 UI 依赖。
- 不修改自定义模型推理契约、路由或模型包格式。
