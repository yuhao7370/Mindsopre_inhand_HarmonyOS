# 人像分割双区预览设计

## 目标

将人像分割页由“相机与分割结果叠在同一区域”改为上下两个同时可见的预览区：

1. 上方“相机原画”只显示实时相机。
2. 下方“分割效果”显示前景蒙版与所选背景的合成结果。
3. 两个预览都保持源画面比例，不拉伸人物。
4. 支持原背景、四套内置背景和自定义相册背景。

本次不更换分割模型、不改变功能入口与可见性，也不引入第三方 UI 依赖。

## 页面结构

- 保留现有原生导航栏、返回、切换摄像头和保存操作。
- 内容使用可滚动纵向布局，依次为：
  - “相机原画”标题与实时预览；
  - “分割效果”标题与合成预览；
  - 运行状态、错误信息和重试入口；
  - 背景选择条。
- 两个预览使用相同的 4:3 容器和 `ImageFit.Cover`，只允许居中裁切，不允许非等比缩放。
- 矮屏或大字体下由页面滚动保证所有操作可达；预览不依赖 `layoutWeight` 强行填满剩余空间。
- 预览卡片沿用项目的浅色细边框和约 16vp 圆角，不增加重阴影。
- 背景缩略图约 72vp，触控区域不小于 44vp；选中态同时使用描边和勾选标记，不能只依赖颜色。

## 图像与状态

- 上方预览直接使用实时相机 Surface，不叠加分割层。
- 相机帧只进行一次方向归一化；分割前景沿用同一逻辑方向和宽高比。
- 前置摄像头镜像只应用一次，并在上下预览保持一致。
- 切换背景只重新合成最近一次有效前景，不重新运行分割推理。
- “原背景”使用与当前分割帧一致的原始画面作为背景。
- 分割执行中或失败时保留最近一次有效合成结果，并显示现有加载、失败和重试状态。
- 保存操作只保存下方“分割效果”，不保存整页截图。

## 背景素材

使用 ImageGen 生成四张 4:3、无人物、无文字、无标志的背景图，并放入 `entry/src/main/resources/rawfile/portrait/`：

- 冷蓝科技影棚；
- 暖色现代室内；
- 柔和自然庭院；
- 蓝白极简渐变。

背景图允许在 `Cover` 模式下少量居中裁切，但不得被拉伸。保留自定义相册入口作为第六项。

## 最小实现范围

- 调整现有 `FeatureRuntimePage.ets` 人像分割布局和复用已有合成状态。
- 仅在方向、比例或背景选择逻辑无法被现有守卫覆盖时增加最小辅助函数。
- 更新现有背景目录与背景选择目录，不创建新的页面、状态管理层或通用组件体系。

## 验证

自动检查应覆盖：

- 相机 Surface 与合成结果位于两个相邻预览区，不再处于同一叠加 `Stack`；
- “相机原画”在“分割效果”之前；
- 两个区域采用相同比例且使用 `ImageFit.Cover`；
- 背景切换不触发新一轮分割；
- 保存目标仍为合成结果；
- 页面在大字体和矮屏下可滚动到背景选择与重试操作。

模拟器验收应覆盖：

- 前、后摄像头画面方向正确且人物不变形；
- 上方原画和下方分割结果的方向、裁切、镜像一致；
- 原背景、四套内置背景和自定义相册均可切换；
- 加载、失败、重试和保存可用；
- 默认字体与 3.2 倍字体下无控件重叠或操作不可达。

## 验收标准

1. 页面明确显示上下两个预览，上方为相机、下方为分割结果。
2. 人物在两个预览中均保持比例，不出现横向或纵向拉伸。
3. 背景切换即时更新下方结果，不重复推理。
4. 四张内置背景符合无人物、无文字、无标志要求。
5. 前后摄像头的方向与镜像表现一致。
6. 页面状态、重试、保存和相册背景入口保持可用。
7. 自动守卫、构建及模拟器截图验收通过。
