# 人像分割与图像分类相册输入设计

## 目标

在人像分割和图像分类页面保留现有实时相机能力，同时允许用户从系统相册选择一张图片并立即推理。

## 交互

- 页面仍默认启动实时相机。
- 两个页面的顶部操作区增加相册入口。
- 选择图片后停止实时相机和连续推理，在原预览区域完整显示所选图片，并自动执行一次推理。
- 静态图片模式提供相机入口，点击后清除静态输入并恢复实时相机与连续推理。
- 用户取消相册选择时保留当前输入和结果。
- 相册图片及其人像分割结果不应用前置摄像头镜像。

## 实现范围

- 复用现有 `PickerService.pickImage()`、图片 URI 推理链路和权限请求。
- 为 `PORTRAIT_SEGMENTATION` 与 `IMAGE_CAMERA` 工作流声明 `photo` 输入和媒体权限。
- 扩展现有专用页面布局，使其能在实时相机和静态图片之间切换。
- 静态图片使用 `ImageFit.Contain` 保持原始比例；不新增页面、推理服务或第三方依赖。

## 状态与错误处理

- 选图成功后自动运行一次当前工作流。
- 推理期间显示现有加载状态，成功或失败沿用现有状态与重试文案。
- 取消选图或选图失败不清除此前可用的预览和推理结果。
- 切回相机时停止静态推理请求，避免旧结果覆盖实时结果。

## 验证

- 单元测试覆盖两个工作流的输入声明、自动推理和静态图片镜像策略。
- 构建 HAP 并安装到 DevEco Studio 模拟器。
- 使用原生触点与截图分别验证人像分割、图像分类的相册选择、静态结果、切回相机和取消选择。
