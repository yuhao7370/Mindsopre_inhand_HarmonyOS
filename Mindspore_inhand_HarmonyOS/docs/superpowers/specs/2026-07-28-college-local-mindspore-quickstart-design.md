# 学院纯本地 MindSpore 快速入门设计

## 目标

隐藏学院页中已经失效的旧“快速入门”和 FAQ 入口，改为应用内可完整阅读的纯本地 MindSpore 实践教程。教程以 PyTorch 经典 MNIST 手写数字识别入门为参照，使用 MindSpore 重写并记录本机实际执行过程，不包含“参考视频”、网页链接或在线下载入口。

## 内容来源

- 在当前开发环境实际检查 Python、MindSpore、PyTorch 和可用数据集。
- 实际执行可行的 MNIST 数据准备、网络构建、训练、评估与模型导出步骤。
- 教程明确记录工具版本、命令、核心代码、输出指标、耗时及遇到的环境限制。
- 若某一步受当前操作系统或工具链限制，教程如实记录失败原因与可复现替代步骤，不伪造执行结果。

## 教程结构

学院页新增“本地快速入门”单列区域，包含以下可展开章节：

1. 实验目标与环境：说明用 MindSpore 复现 PyTorch 经典手写数字分类流程，并列出实测环境。
2. 数据准备：说明数据来源、张量形状、归一化与批处理，附实际命令和代码。
3. 构建网络：给出 MindSpore 网络、损失函数和优化器代码，并解释其与 PyTorch 入门写法的对应关系。
4. 训练与评估：给出可运行训练代码、实测日志、准确率和耗时。
5. 导出与端侧使用：记录模型导出结果、产物格式，以及在 HarmonyOS/MindSpore Lite 中接入时需要的输入输出契约。

每章包含标题、学习目标、正文、等宽代码块和实测记录；不使用“参考视频”章节。

## 交互与视觉

- 继续使用学院页现有 Scroll，不增加第二层滚动。
- 章节使用单列浅边框列表，16vp 圆角、白色背景、无常驻阴影。
- 默认展开第一章；点击整行切换展开状态，一次只展开一章。
- 标题左对齐，使用短蓝色强调条；展开箭头同时提供文字状态，不能只靠颜色表达。
- 正文支持系统字体缩放；代码块自动换行，避免水平滚动。
- 页面保留底部安全空间，不被悬浮导航遮挡。

## 可见性与保留策略

- 原始 `collegeItems` 中的 `quick` 和 `faq` 数据继续保留，但学院页改用过滤后的可见列表。
- 原旧快速入门的四个外链动作（包括“参考视频”）不再渲染。
- FAQ 不再渲染。
- MindSpore 简介、端云协同、论坛和页脚保持现状。

## 数据与文件边界

- 新建独立的本地教程目录文件，保存章节数据和可见性过滤函数。
- `CollegePage.ets` 只负责展开状态和 ArkUI 渲染，不包含训练逻辑。
- 新增一份 Markdown 实验记录，保存完整复现命令与终端结果，供后续维护教程内容。
- 不新增第三方依赖、网络权限、WebView 或页面路由。

## 验证

- 单元测试保证旧 `quick`、`faq` 不在可见列表中，原始数据仍存在。
- 单元测试保证本地教程章节完整、顺序固定、无 URL、无“参考视频”内容，并包含实测记录。
- 完整 LocalUnit 与 HAP 构建通过。
- 在 DevEco Studio 模拟器使用 HDC 原生触点验证默认展开、章节切换、长内容滚动、字体可读性和底部安全区，并保存截图。
